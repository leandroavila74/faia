# FAIA — Framework de Adoção de IA

> Um guia de 7 fases para times de engenharia que querem adotar IA de forma estruturada e sustentável — do diagnóstico organizacional à escala corporativa.

🔗 **[faia.vercel.app](https://faia.vercel.app)**

---

## Origem

Este projeto nasceu durante o workshop da comunidade **[Tech Leads Club](https://techleadsclub.com.br)** realizado nos dias **16 e 17 de maio de 2026**. A ideia foi transformar o conteúdo discutido em um guia de bolso digital — acessível, open source e fácil de consultar tanto no celular quanto no desktop.

---

## O que é o FAIA

O FAIA organiza a jornada de adoção de IA em engenharia em **7 fases progressivas**:

| Fase | Nome |
|------|------|
| 1 | Diagnóstico Organizacional |
| 2 | Curadoria de Ferramentas |
| 3 | Piloto Controlado |
| 4 | Expansão Guiada |
| 5 | Adoção em Escala |
| 6 | Otimização e Governança |
| 7 | IA como Cultura |

Cada fase documenta objetivos, critérios de entrada e saída, gates de qualidade, rituais e métricas de acompanhamento.

## Stack

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **React Router v7**
- Deploy via **Vercel**

---

## Rodando localmente

```bash
git clone https://github.com/leandroavila74/faia.git
cd faia
npm install
npm run dev
```

Acesse `http://localhost:5173`

## Contribuindo

Contribuições são bem-vindas! Como o projeto é **estático e open source**, você pode:

- Corrigir ou expandir o conteúdo das fases em `src/phases/`
- Adicionar novas ferramentas ou referências em `src/pages/Recursos.tsx`
- Melhorar os dados de trilhas em `src/pages/Trilhas.tsx`
- Propor melhorias de layout ou acessibilidade

Abra uma issue ou envie um pull request.
